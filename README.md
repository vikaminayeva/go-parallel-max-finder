# Параллельный поиск максимума в массиве данных на Go (Многопоточность) 
Практический проект на языке **Go**, демонстрирующий возможности конкурентного программирования. Программа генерирует массив из **10 миллионов случайных чисел** и находит среди них максимальное значение двумя способами: классическим однопоточным алгоритмом и параллельным (в 8 потоков) с использованием горутин. Проект наглядно измеряет и сравнивает скорость выполнения обоих подходов.

##  Описание алгоритма и архитектуры

Проект реализован в рамках пакета `main` и базируется на декомпозиции задачи на независимые вычислительные сегменты:

1.  **Генерация данных (`generateRandomElements`):** Алгоритмически создает слайс заданного размера (`SIZE = 10 000 000`) и заполняет его случайными положительными числами с помощью пакета `math/rand`. Безопасно обрабатывает пограничные случаи (например, нулевой размер).
2.  **Последовательный поиск (`maximum`):** Классический линейный обход слайса за время \(O(N)\) в один поток. Используется в качестве эталона для замера производительности.
3.  **Параллельный поиск (`maxChunks`):** 
    *   Большой слайс динамически делится на 8 равных частей (согласно константе `CHUNKS`).
    *   Поиск локального максимума в каждом сегменте запускается асинхронно в отдельной **горутине** через цикл.
    *   Синхронизация потоков и ожидание завершения всех горутин контролируется с помощью структуры **`sync.WaitGroup`**.
    *   Найденные локальные максимумы сохраняются в промежуточный слайс, среди элементов которого вычисляется финальное максимальное значение.

##  Тестирование 

Проект включает в себя полноценное покрытие юнит-тестами в файле `main_test.go`:
*   **Тест генератора:** Проверяет корректность длины создаваемого слайса и обработку экстремальных входных параметров.
*   **Тест поиска максимума:** Валидирует корректность вычислений на различных пограничных сценариях (пустой слайс, слайс из одного элемента, одинаковые числа).

### Измерение производительности:
Для фиксации времени работы алгоритмов используется пакет `time`. Замеры производятся с точностью до **микросекунд (mcs)**. Многопоточный подход демонстрирует кратное увеличение скорости обработки на многоядерных процессорах.

## Технологический стек & Фишки Go

*   **Concurrency Core:** Использование легковесных потоков (**Goroutines**) для параллельных вычислений.
*   **Синхронизация:** Применение примитивов синхронизации пакета `sync` (`WaitGroup.Add`, `Done`, `Wait`).
*   **Слайсинг:** Эффективное разделение памяти через встроенные срезы Go (`slice[start:end]`) без дополнительного копирования данных в куче.
*   **Проектирование тестов:** Использование стандартного пакета `testing` для контроля качества кода.

##  Инструкция по запуску и тестированию

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта:
   ```bash
   cd название_папки_проекта
   ```
3. Запустите автоматические тесты:
   ```bash
   go test -v .
   ```
4. Запустите программу для сравнения скорости в один и восемь потоков:
   ```bash
   go run main.go
   ```
